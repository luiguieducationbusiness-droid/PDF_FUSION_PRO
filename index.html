Conversión y combinación local

Todos tus documentos PDF, en un solo lugar.

Convierte imágenes a PDF, extrae páginas de PDF como imágenes y combina múltiples archivos en un único documento. El procesamiento se realiza directamente en tu navegador.

1. Agrega imágenes

Suelta tus imágenes aquíJPG, JPEG, PNG, WEBP · Puedes seleccionar varias

2. Configura el PDF

PDF → imágenes

Selecciona un PDFLas páginas se renderizan como imágenes PNG en tu dispositivo.

Exportación

Cada página se descarga como PNG. Para documentos extensos, una escala menor reduce el uso de memoria.

Combinar PDFs

Agrega varios archivos PDFEl orden de la lista será el orden final del documento.

Orden y exportación

Puedes reorganizar los archivos con los botones ↑ y ↓ antes de combinarlos. El resultado conserva las páginas de cada PDF.

Convertir imágenes

Suelta tus imágenes aquíJPG, JPEG, PNG, WebP, GIF o SVG · Puedes seleccionar varias

Formato de salida

El procesamiento se realiza localmente. SVG se exporta como un archivo vectorial que contiene la imagen seleccionada.
